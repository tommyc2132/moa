# 모아 (Moa) 📸

[⬇️ 모아 내려받기](https://github.com/tommyc2132/moa/releases/tag/v0.1.0-preview.2-docs.1)

화면을 캡처하고, 여러 사진을 한 보드에 모아 설명하는 Windows 앱입니다. 캡처한 화면이나 받은 스크린샷을 자유롭게 배치하고, 글씨·번호·말풍선·화살표로 필요한 내용을 표시하세요.

> Windows 10 (2004 이상) / 11 · Intel / AMD x64 · 알림 영역 상주 · 설치 없이 실행

---

## 📥 다운로드 및 실행

1. [릴리스](https://github.com/tommyc2132/moa/releases/tag/v0.1.0-preview.2-docs.1)에서 아래 파일을 받습니다.

| 파일 | 사용법 |
|---|---|
| [Moa.exe](https://github.com/tommyc2132/moa/releases/download/v0.1.0-preview.2-docs.1/Moa.exe) | 원하는 폴더에 보관한 뒤 바로 실행 |
| [포터블 ZIP](https://github.com/tommyc2132/moa/releases/download/v0.1.0-preview.2-docs.1/Moa-0.1.0-preview.2-windows-x64.zip) | 압축을 풀고 폴더 안의 `Moa.exe` 실행 |

2. 실행하면 오른쪽 아래 알림 영역에 모아 아이콘이 나타납니다. 숨겨져 있다면 시계 옆 `^` 안에서 찾으세요.
3. **Ctrl+Shift+3**을 누르고 영역을 드래그한 뒤 놓으면 캡처합니다.

.NET을 따로 설치하지 않아도 사용할 수 있습니다.

## 🔄 업데이트

앱의 업데이트 메뉴를 누르면 모아 릴리스 페이지가 열립니다. 새 실행 파일을 내려받고, 트레이에서 **모아 종료**를 누른 뒤 `Moa.exe`를 교체하세요.

## ✨ 주요 기능

- **영역 캡처** — 영역을 드래그하고 놓으면 바로 캡처. 설정에서 캡처 단축키를 바꿀 수 있습니다.
- **영역 녹화** — 별도 단축키로 녹화를 시작하고 중지합니다.
- **라이브러리 편집** — 캡처를 모아 보고, 크롭·가로/세로 띠 잘라내기·주석 편집. 여러 캡처를 선택해 휴지통으로 보낼 수 있습니다.
- **사진 보드** — 캡처와 다운로드한 이미지 여러 장을 한곳에 배치. 파일 추가·드래그·붙여넣기를 지원합니다.
- **사진 이동·크기 조절** — 테두리와 조절점, 드래그 시작 위치와 현재 크기·위치를 보며 조절합니다. 큰 보드는 Space+드래그로 이동합니다.
- **글씨와 주석** — 번호·텍스트·말풍선·직선/곡선 화살표·도형·모자이크. 글꼴·글자 크기·색·굵게·기울임·밑줄을 바꾸고, 글씨와 말풍선도 모서리로 크기를 조절합니다.
- **장면과 그룹** — 여러 장면을 추가·복제·정렬하고, 사진과 주석을 묶어서 함께 이동·크기 조절합니다.
- **번호 설명** — 번호마다 현재 문제·원하는 동작·완료 조건을 작성하고 보드에서 바로 확인합니다.
- **고해상도 출력** — 사진 크기를 바꿔도 보관한 원본 PNG를 유지하고, 사진과 주석으로 고해상도 이미지를 만듭니다.
- **편집 가능한 저장** — `.osboard`로 저장해 이어서 수정하거나, PNG·번호 설명 이미지·장면별 설명 문서로 내보냅니다.

## 🧩 보드 사용하기

1. 트레이의 **보드…** 또는 라이브러리에서 **Ctrl+Shift+B**로 보드를 엽니다.
2. **파일로 새 보드**에서 이미지 여러 장을 선택합니다. 열린 보드에는 **파일 추가**, 파일 드래그, **Ctrl+V**로 사진을 더하세요.
3. 선택 도구 **V**로 사진을 이동하고 테두리 조절점으로 크기를 바꿉니다. 모서리는 비율을 유지하고, 변 가운데는 한 방향만 조절합니다.
4. 텍스트·번호·말풍선·화살표를 추가합니다. 글씨는 더블클릭해 수정하고, **Shift+Enter**로 줄을 바꿉니다.
5. 상단 **보드 이름**에서 이름을 정하고 **Ctrl+S**로 저장합니다.

- **보드 크기**에서 작업 공간을 넓히고, **표준 1600×1200**으로 내용을 맞출 수 있습니다.
- 왼쪽 **장면** 탭에서 장면을 관리합니다. 장면 우클릭으로 이름 변경·복제·이동·삭제·삭제한 장면 복구를 사용하세요.
- **새 보드 ▼ → 보드 초기화**는 현재 장면을 비웁니다. **Ctrl+Z**로 되돌릴 수 있습니다.

### 번호 설명 보기

선택 도구 **V**로 번호 하나를 클릭한 뒤, 왼쪽 **번호 설명** 탭에 내용을 입력하세요. 번호 옆 설명 카드에 바로 표시됩니다. 긴 내용은 카드 안에서 스크롤하고, 닫았으면 **보드에서 설명 보기**를 체크해 다시 엽니다.

설명을 함께 전달하려면 **번호 설명 탭 맨 아래 → 설명 내보내기**를 사용하세요. 상단 도구막대에도 같은 메뉴가 있습니다.

## ⌨️ 단축키

| 동작 | 키 |
|---|---|
| 캡처 시작 | `Ctrl+Shift+3` — 설정에서 변경 가능. `Shift+S` 같은 조합도 지정 가능 |
| 영역 녹화 시작 / 중지 | `Ctrl+Shift+4` |
| 보드 열기 | 라이브러리에서 `Ctrl+Shift+B` |
| 선택 도구 | `V` |
| 텍스트 / 번호 / 말풍선 | `Ctrl+T` / `Ctrl+1` / `Ctrl+2` |
| 직선 / 곡선 화살표 | `Ctrl+3` / `Ctrl+4` |
| 글씨 굵게 / 기울임 / 밑줄 | 글씨 편집·선택 시 `Ctrl+B` / `Ctrl+I` / `Ctrl+U` |
| 글씨 줄바꿈 / 작성 완료 | `Shift+Enter` / `Enter` |
| 보드 화면 이동 | `Space`를 누른 채 왼쪽 드래그 |
| 화면 맞춤 / 100% 보기 | `Ctrl+0` / `Ctrl+9` |
| 여러 항목 선택 | `Ctrl`·`Shift`+클릭 또는 빈 공간 드래그 |
| 그룹 / 그룹 해제 | `Ctrl+G` / `Ctrl+Shift+G` |
| 선택 복제 / 삭제 | `Ctrl+D` / `Delete` |
| 되돌리기 / 다시 실행 | `Ctrl+Z` / `Ctrl+Y` |
| 보드 저장 / 열기 | `Ctrl+S` / `Ctrl+O` |

장면 목록에 포커스가 있을 때 `Delete`는 장면 삭제, `Ctrl+D`는 장면 복제, `F2`는 장면 이름 변경입니다. 라이브러리에서는 캡처를 선택한 뒤 우클릭 메뉴의 `B` 또는 `Delete`로 휴지통에 보냅니다.

## 💾 저장과 내보내기

| 형식 | 용도 |
|---|---|
| **보드 저장 (.osboard)** | 사진·주석·장면·번호 설명을 보관하고 다시 편집 |
| **PNG 내보내기 / 전체 복사** | 사진과 주석을 합성한 이미지 |
| **현재 장면 + 번호 설명 PNG…** | 현재 장면과 번호별 설명을 한 이미지로 저장 |
| **전체 장면 + 설명 문서 (.md)…** | 장면별 PNG와 번호 설명 Markdown 저장 |

장면별 설명 문서를 전달할 때는 문서 옆의 이미지 폴더도 함께 보내세요. 번호 옆 설명 카드는 편집 화면에 표시되며, 설명을 이미지에 담으려면 **설명 내보내기**를 사용합니다.

## 🗑 종료 및 삭제

보드 창의 X는 작업을 임시 보관하고 창을 숨깁니다. 앱을 완전히 종료하려면 트레이의 **모아 종료**를 누르세요.

앱을 삭제하려면 설정에서 Windows 로그인 시 자동 실행을 해제한 뒤, 앱을 종료하고 실행 파일을 삭제합니다. 저장해 둔 캡처와 보드 파일은 별도로 보관됩니다.
