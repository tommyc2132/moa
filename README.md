# 모아 · Moa

캡처한 화면과 받은 사진을 한 보드에 모으고, 주석과 설명으로 전달하는 Windows 앱입니다.

> **비공개 검토 버전 · 0.1.0-preview.2**
> 완성 전까지 저장소와 다운로드 파일을 비공개로 유지합니다. 접근 권한이 있는 GitHub 계정으로 로그인해야 열 수 있습니다.

- Windows 10(2004 이상)/11의 **Intel·AMD x64 PC용**입니다. ARM64 전용 빌드는 제공하지 않습니다.
- .NET 런타임을 포함하므로 별도 .NET 설치가 필요 없습니다.
- 원하는 폴더에 보관하고 `Moa.exe`를 실행하세요. 설치 프로그램이 아니며 관리자 권한 설치 없이 사용합니다.
- 아직 코드 서명을 하지 않은 검토 빌드입니다. 다운로드한 파일의 출처와 해시는 이 저장소의 릴리스에서 확인할 수 있습니다.

## 처음 사용하기

1. `Moa.exe`를 실행합니다. 오른쪽 아래 알림 영역의 모아 아이콘을 누르면 메뉴가 열립니다. 숨겨져 있다면 `^` 안에서 찾으세요.
2. **Ctrl+Shift+3**을 누르고 영역을 드래그한 뒤 놓으면 바로 캡처합니다. Enter 확인은 필요 없습니다.
3. 트레이 메뉴의 **보드…** 또는 라이브러리의 **Ctrl+Shift+B**로 보드를 엽니다. 실행 파일에 `--board`를 붙여 바로 열 수도 있습니다.
4. **파일로 새 보드**에서 다운로드한 스크린샷 여러 장을 선택합니다. 열린 보드에는 **파일 추가**, 파일 드래그, **Ctrl+V**로 사진을 더할 수 있습니다.
5. 사진을 배치하고 번호·글씨·말풍선·화살표를 추가합니다. **Ctrl+S**로 `.osboard`를 저장하면 나중에 다시 편집할 수 있습니다.

## 보드에서 할 수 있는 일

| 작업 | 사용법 |
|---|---|
| 사진 이동·크기 조절 | 선택 도구 **V**에서 드래그. 모서리는 비율 유지, 변 가운데는 한 방향 조절. 현재 테두리·원래 위치 점선·크기 안내를 표시합니다. |
| 큰 보드 이동 | **Space를 누른 채 왼쪽 드래그**. Ctrl+0 화면 맞춤, Ctrl+9 화면 100%. |
| 글씨·말풍선 조절 | 선택 후 네 모서리로 크기 조절. 본문을 잡고 이동하고, 더블클릭해 내용 수정. 글꼴·색·굵게·기울임·밑줄을 지원합니다. |
| 여러 항목 묶기 | Ctrl/Shift+클릭 또는 빈 공간 드래그로 선택 → **Ctrl+G**. Ctrl+Shift+G로 해제. |
| 여러 장면 만들기 | 왼쪽 **장면** 탭에서 추가·복제·순서 변경. 우클릭으로 이름 변경·삭제·삭제한 장면 복구. 목록 Delete는 장면 삭제. |
| 보드 크기 바꾸기 | **보드 크기**에서 확대하거나 **표준 1600×1200**으로 내용에 맞춰 복원. Ctrl+Z로 되돌립니다. |
| 현재 장면 비우기 | **새 보드 ▼ → 보드 초기화**. Ctrl+Z로 복원 가능. |

사진의 크기를 바꿔도 보드 내부의 원본 PNG 자산은 유지됩니다. 고해상도 출력은 보관한 사진 원본과 주석에서 다시 그립니다. 원본 사진에 없는 디테일을 새로 만드는 기능은 아닙니다.

## 번호와 설명을 함께 전달하기

1. **Ctrl+1**로 번호를 찍고 선택 도구 **V**로 그 번호 하나를 클릭합니다.
2. 왼쪽 **번호 설명** 탭에서 **현재 문제 / 원하는 동작 / 완료 조건**을 작성합니다. 저장하거나 다시 열지 않아도 번호 옆의 설명 카드에 즉시 표시됩니다.
3. 긴 내용은 카드 안에서 스크롤합니다. 닫았으면 **보드에서 설명 보기**를 다시 체크하세요.
4. **번호 설명 탭 맨 아래 → 설명 내보내기**를 누릅니다. 상단의 **보드 이름**과 **PNG 내보내기** 사이에도 같은 메뉴가 있습니다.

| 내보내기 | 결과 |
|---|---|
| **현재 장면 + 번호 설명 PNG…** | 현재 장면 아래에 번호별 설명을 붙인 이미지 한 장 |
| **전체 장면 + 설명 문서 (.md)…** | 순서대로 모든 장면 PNG와 설명 Markdown. 문서 옆 이미지 폴더도 함께 전달하세요. |
| **PNG 내보내기 / 전체 복사** | 설명 카드·편집 UI 없이 사진과 주석만 합성한 이미지 |

`.osboard`는 편집용 저장 파일입니다. 설명을 이미지에 함께 넣어 전달하려면 **설명 내보내기**를 사용하세요.

## 자주 쓰는 단축키

| 키 | 동작 |
|---|---|
| Ctrl+Shift+3 | 이미지 캡처. 설정에서 변경 가능하며 Shift+S 같은 조합도 지정 가능 |
| Ctrl+Shift+4 | 영역 녹화 시작 / 다시 눌러 중지 |
| Ctrl+T / Ctrl+1 / Ctrl+2 | 텍스트 / 번호 / 말풍선 |
| Ctrl+3 / Ctrl+4 | 직선 화살표 / 곡선 화살표 |
| Ctrl+B / Ctrl+I / Ctrl+U | 글씨 문맥에서 굵게 / 기울임 / 밑줄 |
| Shift+Enter / Enter | 글씨 줄바꿈 / 작성 완료 |
| Ctrl+Z / Ctrl+Y | 되돌리기 / 다시 실행 |
| Ctrl+S / Ctrl+O | 보드 저장 / 열기 |
| Ctrl+D / Delete | 선택 복제 / 삭제. 장면 목록에 포커스가 있으면 장면에 적용 |

## 저장과 업데이트

- 기본 캡처 폴더는 `사진\OpenSnapPlus`, 설정·임시 복구 위치는 `%APPDATA%\OpenSnapPlus`입니다.
- 보드 창의 X는 작업을 임시 보관한 뒤 숨깁니다. 앱을 완전히 종료하려면 트레이의 **모아 종료**를 누르세요.
- 업데이트 메뉴는 **모아 Releases 페이지**를 엽니다. 앱 종료 후 새 `Moa.exe`로 교체하세요.
