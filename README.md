# 모아 (Moa) 📸

[⬇️ Windows 내려받기](https://github.com/tommyc2132/moa/releases/tag/v0.1.0-preview.7) · [🍎 Mac 내려받기](https://github.com/tommyc2132/moa/releases/tag/v0.1.0-mac-preview.5)

화면을 캡처하고, 여러 사진을 한 보드에 모아 설명하는 Windows · Mac 앱입니다. 캡처한 화면이나 받은 스크린샷을 자유롭게 배치하고, 글씨·번호·말풍선·화살표로 필요한 내용을 표시하세요.

> Windows 10 (2004 이상) / 11 · Intel / AMD x64
> Mac: macOS 13 이상 · Apple Silicon / Intel Universal · 미리보기

---

개인 테스트용 미리보기로 개발자 인증·공증 전입니다. 실행이 차단되면 **시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기**에서 실행을 허용합니다. 캡처할 때 **화면 및 시스템 오디오 기록** 권한을 허용하고 앱을 다시 실행해 주세요.

- **Control+Shift+3**: 영역을 드래그하고 놓으면 원본 크기 PNG 저장·복사. Enter는 필요 없습니다.
- **Control+Shift+4**: 녹화 영역 선택 후 시작하고, 같은 키로 중지합니다. **무음 MP4**입니다.
- **Command+L**: 라이브러리 · **Command+Shift+B**: 보드.
- **Command+T / 1 / 2 / 3 / 4**: 텍스트 / 번호 / 말풍선 / 화살표 / 곡선 화살표.
- **Command+B / Command+Shift+I / Command+U**: 굵게 / 기울임 / 밑줄.
- **Command+S**: 보드 저장 · **Command+Z**: 실행 취소 · **Shift+Enter**: 줄바꿈.
- 사진 파일 추가·붙여넣기·드래그, 사진/글씨/말풍선 모서리 조절, Space+드래그, 장면·번호 설명·PNG 내보내기를 지원합니다.
- **모아 → 모아 설정**에서 캡처 단축키(Shift+S 가능), 저장 폴더, 소리와 자동 열기를 바꿉니다.
- 영상은 라이브러리에서 두 번 클릭해 재생하고, 구간을 지정해 MP4/GIF로 저장합니다. GIF는 최대 60초입니다.
- `.osboard`는 Windows 모아와 함께 사용할 수 있습니다. 설치된 글꼴이 다르면 글씨 모양과 배치가 달라질 수 있습니다.
- 창을 닫아도 메뉴 막대에서 계속 실행됩니다. **Command+Q** 또는 **모아 종료**로 종료합니다.

아래의 트레이 안내와 Ctrl 중심 단축키는 **Windows 기준**입니다. Mac은 위 단축키와 상단 메뉴를 사용하세요.

## 숫자 주석 크기 조절

선택 도구 **V**로 번호 하나를 클릭하고, 선택 테두리의 **모서리 조절점**을 드래그하세요. 원과 숫자가 함께 확대·축소됩니다. 조절 중 크기와 시작 위치가 표시되며, **Esc**로 취소하거나 실행 취소로 되돌릴 수 있습니다. 번호와 연결된 설명도 유지됩니다. 크기는 지름 **12–512px**, 보드 안에서 조절됩니다. `.osboard`에 크기를 저장하며 양쪽 기기에서 최신 버전으로 편집하세요.

## 글씨 일부만 꾸미기 · 직접 그리기

텍스트나 말풍선을 **두 번 클릭**해 편집한 뒤, 바꾸고 싶은 단어·문장을 드래그해 선택하세요. 상단에서 **글자 색·글꼴·크기·굵게·기울임·밑줄**을 바꾸면 선택한 부분에만 적용됩니다. 서식 도구를 눌러도 선택한 범위를 유지합니다.

- 편집 중 선택한 글자가 없으면 바꾼 서식은 **이후 입력하는 글자**에 적용됩니다.
- 편집을 마친 뒤 선택 도구로 주석 자체를 선택하면 주석 전체 서식을 바꿀 수 있습니다.
- **펜** 도구를 누르고 마우스를 누른 채 그리세요. Windows **Ctrl+8**, Mac **Command+8**로 선택합니다. 색과 선 굵기를 바꿀 수 있고, **Esc**로 그리는 중인 선을 취소합니다.
- 부분 서식과 펜 경로도 `.osboard`에 저장됩니다. 양쪽 기기에서 이번 버전 이상을 사용하세요.

새 캡처의 기본 저장 위치는 **사진(Pictures) → 스크린샷**입니다. 기존 기본 폴더의 캡처도 라이브러리에 함께 표시하며 파일을 이동하거나 삭제하지 않습니다. 사용자가 별도로 지정한 저장 위치는 유지합니다.

## 텍스트 목록과 제목

텍스트와 말풍선에서 줄 맨 앞에 아래 형식으로 입력하세요. 기호 뒤에 **공백**이 필요합니다.

```text
# 제목
## 부제목
- 글머리 항목
  - 두 번째 단계
1. 번호 항목
2. 다음 항목
```

- 목록에서 **Enter**: 다음 글머리·번호를 자동으로 이어 씁니다. 빈 항목에서 Enter를 누르면 한 단계 나오거나 목록을 끝냅니다.
- **Tab / Shift+Tab**: 들여쓰기 / 내어쓰기. 기본 단계와 하위 단계, **총 2단계**까지만 지원합니다. 여러 줄을 선택해 함께 바꿀 수 있습니다.
- **Shift+Enter**: 일반 줄바꿈. **Ctrl+Enter**(Mac: **Command+Enter**)로 목록 편집을 완료할 수 있습니다.
- 일반 텍스트는 **Enter**로 편집 완료합니다. 입력 중에는 `#`, `-` 같은 작성 기호가 보이고, 완료하면 제목 크기·글머리·들여쓰기가 보드와 PNG에 반영됩니다.
- 제목은 `#`, `##` 두 종류입니다. `###`는 입력한 글자로 표시합니다.

## 🔄 업데이트

앱의 업데이트 메뉴를 누르면 모아 릴리스 페이지가 열립니다. 새 실행 파일을 내려받고, 트레이에서 **모아 종료**를 누른 뒤 `Moa.exe`를 교체하세요.

## ✨ 주요 기능

- **영역 캡처** — 영역을 드래그하고 놓으면 바로 캡처. 설정에서 캡처 단축키를 바꿀 수 있습니다.
- **영역 녹화** — 별도 단축키로 녹화를 시작하고 중지합니다.
- **라이브러리 편집** — 캡처를 모아 보고, 크롭·가로/세로 띠 잘라내기·주석 편집. 여러 캡처를 선택해 휴지통으로 보낼 수 있습니다.
- **사진 보드** — 캡처와 다운로드한 이미지 여러 장을 한곳에 배치. 파일 추가·드래그·붙여넣기를 지원합니다.
- **사진 이동·크기 조절** — 테두리와 조절점, 드래그 시작 위치와 현재 크기·위치를 보며 조절합니다. 큰 보드는 Space+드래그로 이동합니다.
- **글씨와 주석** — 번호·텍스트·말풍선·직선/곡선 화살표·펜·도형·모자이크. 글꼴·글자 크기·색·굵게·기울임·밑줄을 바꾸고, 글씨와 말풍선도 모서리로 크기를 조절합니다.
- **장면과 그룹** — 여러 장면을 추가·복제·정렬하고, 사진과 주석을 묶어서 함께 이동·크기 조절합니다.
- **번호 설명** — 번호마다 현재 문제·원하는 동작·완료 조건을 작성하고 보드에서 바로 확인합니다.
- **고해상도 출력** — 사진 크기를 바꿔도 보관한 원본 PNG를 유지하고, 사진과 주석으로 고해상도 이미지를 만듭니다.
- **편집 가능한 저장** — `.osboard`로 저장해 이어서 수정하거나, PNG·번호 설명 이미지·장면별 설명 문서로 내보냅니다.

번호·텍스트 도구를 선택하면 네모·원·모자이크 위에도 바로 주석을 추가할 수 있습니다. 기존 도형을 이동하려면 선택 도구를 사용하세요.

## 🧩 보드 사용하기

1. 트레이의 **보드…** 또는 라이브러리에서 **Ctrl+Shift+B**로 보드를 엽니다.
2. **파일로 새 보드**에서 이미지 여러 장을 선택합니다. 열린 보드에는 **파일 추가**, 파일 드래그, **Ctrl+V**로 사진을 더하세요.
3. 선택 도구 **V**로 사진을 이동하고 테두리 조절점으로 크기를 바꿉니다. 모서리는 비율을 유지하고, 변 가운데는 한 방향만 조절합니다.
4. 텍스트·번호·말풍선·화살표를 추가합니다. 글씨는 더블클릭해 수정하고, **Shift+Enter**로 줄을 바꿉니다.
5. 상단 **보드 이름**에서 이름을 정하고 **Ctrl+S**로 저장합니다.

- **보드 크기**에서 작업 공간을 넓히고, **표준 1600×1200**으로 내용을 맞출 수 있습니다.
- 왼쪽 **장면** 탭에서 장면을 관리합니다. 장면 우클릭으로 이름 변경·복제·이동·삭제·삭제한 장면 복구를 사용하세요.
- **새 보드 ▼ → 보드 초기화**는 현재 장면을 비웁니다. **Ctrl+Z**로 되돌릴 수 있습니다.

### 번호 설명 보기

선택 도구 **V**로 번호 하나를 클릭한 뒤, 왼쪽 **번호 설명** 탭에 내용을 입력하세요. 번호 옆 설명 카드에 바로 표시됩니다. 긴 내용은 카드 안에서 스크롤하고, 닫았으면 **보드에서 설명 보기**를 체크해 다시 엽니다.

설명을 함께 전달하려면 **번호 설명 탭 맨 아래 → 설명 내보내기**를 사용하세요. 상단 도구막대에도 같은 메뉴가 있습니다.

## ⌨️ 단축키

| 동작 | 키 |
|---|---|
| 캡처 시작 | `Ctrl+Shift+3` — 설정에서 변경 가능. `Shift+S` 같은 조합도 지정 가능 |
| 영역 녹화 시작 / 중지 | `Ctrl+Shift+4` |
| 보드 열기 | 라이브러리에서 `Ctrl+Shift+B` |
| 선택 도구 | `V` |
| 텍스트 / 번호 / 말풍선 | `Ctrl+T` / `Ctrl+1` / `Ctrl+2` |
| 직선 / 곡선 화살표 | `Ctrl+3` / `Ctrl+4` |
| 자유롭게 그리는 펜 | `Ctrl+8` |
| 글씨 굵게 / 기울임 / 밑줄 | 글씨 편집·선택 시 `Ctrl+B` / `Ctrl+I` / `Ctrl+U` |
| 글씨 줄바꿈 / 작성 완료 | `Shift+Enter` / `Enter` |
| 보드 화면 이동 | `Space`를 누른 채 왼쪽 드래그 |
| 화면 맞춤 / 100% 보기 | `Ctrl+0` / `Ctrl+9` |
| 여러 항목 선택 | `Ctrl`·`Shift`+클릭 또는 빈 공간 드래그 |
| 그룹 / 그룹 해제 | `Ctrl+G` / `Ctrl+Shift+G` |
| 선택 복제 / 삭제 | `Ctrl+D` / `Delete` |
| 되돌리기 / 다시 실행 | `Ctrl+Z` / `Ctrl+Y` |
| 보드 저장 / 열기 | `Ctrl+S` / `Ctrl+O` |

장면 목록에 포커스가 있을 때 `Delete`는 장면 삭제, `Ctrl+D`는 장면 복제, `F2`는 장면 이름 변경입니다. 라이브러리에서는 캡처를 선택한 뒤 우클릭 메뉴의 `B` 또는 `Delete`로 휴지통에 보냅니다.

## 💾 저장과 내보내기

| 형식 | 용도 |
|---|---|
| **보드 저장 (.osboard)** | 사진·주석·장면·번호 설명을 보관하고 다시 편집 |
| **PNG 내보내기 / 전체 복사** | 사진과 주석을 합성한 이미지 |
| **현재 장면 + 번호 설명 PNG…** | 현재 장면과 번호별 설명을 한 이미지로 저장 |
| **전체 장면 + 설명 문서 (.md)…** | 장면별 PNG와 번호 설명 Markdown 저장 |

장면별 설명 문서를 전달할 때는 문서 옆의 이미지 폴더도 함께 보내세요. 번호 옆 설명 카드는 편집 화면에 표시되며, 설명을 이미지에 담으려면 **설명 내보내기**를 사용합니다.

## 🗑 종료 및 삭제

보드 창의 X는 작업을 임시 보관하고 창을 숨깁니다. 앱을 완전히 종료하려면 트레이의 **모아 종료**를 누르세요.

앱을 삭제하려면 설정에서 Windows 로그인 시 자동 실행을 해제한 뒤, 앱을 종료하고 실행 파일을 삭제합니다. 저장해 둔 캡처와 보드 파일은 별도로 보관됩니다.
